# Deployment checklist
- [ ] Rotate any API key ever exposed in screenshots.
- [ ] Add fresh keys to local .env; never commit it.
- [ ] Run local tests and upload a non-sensitive sample PDF.
- [ ] Push source to GitHub without .env, venv, secrets or database.
- [ ] Create Streamlit Community Cloud app with app.py entrypoint.
- [ ] Add GROQ_API_KEY and TAVILY_API_KEY in Streamlit Secrets.
- [ ] Deploy and test in a separate browser session.
- [ ] Record the 30-second demo.
- [ ] Submit deployed URL, GitHub URL and demo URL.
